# PREDICT V3 — conditional expected net return (exploratory)
Separate branch from V2 prospective freeze. No PRD or V2 changes.
Use frozen E2 dataset and E3 predictions, same side-specific 28,445 train, 9,471 validation, 9,536 retrospective test observations, same 30m barrier and timeout labels, same 60/20/20 time cutoffs and embargo. No new data in this experiment. Target = gross realized R minus cost in R, with 0.16% and 0.24% round-trip scenarios. Both stop/target and timeouts included; features remain available at t. Ridge alpha 10, separate fit per direction, two cost outputs, no search. Gate strictly positive predicted net R at both cost assumptions; rank by adverse cost prediction. One portfolio position across both sides, same exit cooldown as V2. Compare against same geometric, compression and frozen V2 p>=0.5 baselines, and constant training mean expected return. Report MSE/MAE vs training mean, calibration by fixed return bins, actual net R, mean R, trade counts, drawdown, PF and day-block bootstrap CIs. Costs not verified; no historical tick/lot, funding, liquidation, PRD state or actual fills. Historical test already inspected, not independent. Even positive results require fresh pre-registered validation, not the reserved V2 window as a tuning set. No orders, alerts, leverage or schedule changes.
